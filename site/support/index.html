Need help with Quizzie?

Help paths without collecting information through a website form.

Quick checks

  • Allow camera permission if the picture scanner does not open.
  • Use a clear, well-lit image for better on-device image labels.
  • Connect to the internet if public learning summaries or remote question packs do not load.
  • If remote content is unavailable, Quizzie can continue with built-in learning content.

Contact path

Quizzie does not use a contact form on this website. Use the support contact shown in the Google Play listing or the repository project page.
