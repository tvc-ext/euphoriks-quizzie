Privacy Policy

Euphoriks Quizzie privacy policy

Effective date: 2 September 2026

Quizzie is designed as a child-friendly, local-first learning app. This policy describes the current implementation.

Summary

Quizzie currently does not provide Euphoriks cloud accounts, a Euphoriks cloud database, ads, purchases, analytics, cookies, trackers, website forms, public chat or social posting. The app stores the child's explorer profile and learning progress on the device.

Information the app asks the child to choose

During onboarding, Quizzie asks the child to choose a broad age band and an explorer avatar. Age bands are 6-8, 9-11 and 12-14. The avatar uses a playful generated alias.

The current app does not ask for a real name, exact age, school, phone number, email address, precise location or account password.

Local storage

Quizzie uses local app storage through Flutter shared preferences. Stored values can include the selected broad age band, explorer avatar ID, curiosity energy, completed topic/game IDs, question history and cached public educational content.

Camera, gallery and image labeling

The picture scanner can ask for camera or gallery access when the child chooses to take or select a picture. Current image labeling uses Google ML Kit on the device. The app does not upload the photo for labeling in the current implementation. A detected label may be used to request a public educational fact summary.

External educational content

Quizzie can request public educational content from third-party public sources, including Wikipedia summary APIs, NASA image search APIs and public GitHub-hosted content. Normal network requests may expose ordinary technical information such as IP address and request metadata to those services.

Accounts and backend

The current Quizzie app has no Euphoriks account system and no Euphoriks cloud database. It does not currently sync a child's profile or progress to an Euphoriks server.

Advertising and tracking

The current app has no ads, ad SDKs, in-app purchases, analytics SDKs or behavioral tracking. This static website has no analytics, cookies, trackers, forms or backend.

Data deletion

The app includes a way to reset the explorer profile and learning progress. A parent can also remove local app data through Android storage controls or by uninstalling the app.

Changes

This policy will be updated before adding accounts, cloud sync, ads, analytics, purchases, friend connections, public sharing or new third-party data flows.

Contact

For support and privacy questions, use the contact path on the Euphoriks Quizzie Support page.

Historical note: Euphoriks Quizzie was previously named CurioVerse. Existing technical identifiers and URLs may retain the former name during the rebrand.
